# Analyst review input files

Each case folder contains:

- `explanation.json`: the full output from the explainability package.
- `decision.json`: explicit analyst ID, outcome, reason, warning acknowledgement
  and a unique submission ID. See the package README for the full schema.

The healthy-business explanation was generated by the current explainability flow
(offline mode) from the live Phase 2 report and its Phase 3 assessment. It and the decision
are fictional. File inputs are read on every run. In an integrated application,
the server should retrieve the stored report and derive analyst identity from
authentication; do not trust arbitrary browser-submitted assessment snapshots.
